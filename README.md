## Research & Engineering Work

- StrokeSeg-xAI — explainable ischemic stroke lesion segmentation on ISLES 2018 CTP maps; hybrid Generalized Dice + Focal Tversky; Grad-CAM saliency and MC-Dropout uncertainty maps.
- Lightweight H&E → Spatial Gene Expression — reproduced TinyH2GNet on HEST-1k HER2; built TinyGPQ (~315k params) with cell-wise PCC 0.463 vs 0.435 baseline.
- UNSW pressure-injury staging — PRISMA-ScR review across 77 screened records; benchmarked Mask R-CNN, CapsNet, and ConvNeXt; found systematic gaps in the literature.
- Rasyn AI document-layout work — synthetic-data pipeline with pseudo-labels from PP-DocLayout / DocLayout-YOLO, DocGrammar schemas, and XY-Cut difficulty control.
- Vagus Labs — AI clinical scribe with dialect-aware symptom mapping to SNOMED CT, ABDM/ABHA integration, and FHIR R4 bundles.
- LLM eval framework — async RAG evaluation over 1.2K FiQA samples, groundedness 4.68, 8% hallucination rate, regression gates in GitHub Actions.
